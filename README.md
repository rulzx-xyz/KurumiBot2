## 🥀 ⟡ Tentang Kurumi MD
**Kurumi MD** adalah bot WhatsApp cerdas yang dikembangkan oleh **RulzxXyz**, dibangun menggunakan Node.js dan ekosistem `@whiskeysockets/baileys`. Didesain dengan pesona elegan Kurumi Tokisaki, bot ini berfungsi sebagai asisten virtual canggih untuk manajemen grup, analisis kode via AI, hingga sinkronisasi sistem mandiri.

## 🕸️ ⟡ Fitur Unggulan (Kekuatan Zafkiel)
- 🧠 **Kurumi AI Assistant:** Asisten cerdas dengan persona Kurumi yang mendukung format *output* AIRich (tabel markdown, blok kode, dan analisis error).
- 🛡️ **Anti-SW Grup (Group Protection):** Auto-deteksi dan hapus (*auto-delete*) Status Grup / Story Grup ilegal di dalam grup.
- 🚀 **SWGC Burst:** Penembak status grup secara massal dan tanpa jeda menggunakan tombol interaktif modern.
- 🕰️ **Time Manipulation (Auto Push):** Sinkronisasi dan pembaruan kode otomatis dari VPS ke GitHub menggunakan perintah `.upscgh`.
- 📊 **Plugin Analyzer:** Melacak garis waktu modifikasi file untuk melihat daftar plugin yang baru ditambahkan atau diperbarui (`.newplugin`).

## ⚙️ ⟡ Instalasi & Ritual Pemanggilan

```bash
# 1. Kloning repositori ini (Panggil Kurumi)
git clone [https://github.com/rulzx-xyz/KurumiBot2.git](https://github.com/rulzx-xyz/KurumiBot2.git)

# 2. Masuk ke direktori bot
cd KurumiBot2

# 3. Instal semua dependensi sistem
npm install

# 4. Bangkitkan Kurumi
npm start
